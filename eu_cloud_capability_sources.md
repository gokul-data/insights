# EU cloud capability signal — sources and method

- Eurostat, “Cloud computing — statistics on the use by enterprises”, published 2 June 2026: https://ec.europa.eu/eurostat/statistics-explained/SEPDF/cache/37043.pdf
- Eurostat Data Browser, dataset `isoc_cicce_use`, last updated 27 February 2026: https://ec.europa.eu/eurostat/databrowser/view/isoc_cicce_use__custom_19644911/bookmark/table?bookmarkId=751b6bd3-143b-4846-b0e7-25f52e185ed0&lang=en

The dashboard preserves Eurostat's denominators. Paid-cloud adoption is a percentage of all enterprises; SaaS/IaaS/PaaS values are percentages among enterprises already using paid cloud. The 2.34× metric is 52.86 ÷ 22.59, rounded to two decimals.
