# UK Retail Pulse — Power BI and DAX

A reproducible BI case study built from the ONS Retail Sales Index (DRSI), released 24 July 2026.

Contents:
- `UK_Retail_Pulse_PowerBI.xlsx` — Power BI-ready fact table, date table, sector summary and DAX catalogue
- `measures.dax` — reusable DAX measure layer
- `uk_retail_powerbi_linkedin.png` — LinkedIn infographic

Model: `DateTable[Date] (1) → FactRetail[Date] (*)`

Source: https://www.ons.gov.uk/businessindustryandtrade/retailindustry/datasets/retailsales/current
